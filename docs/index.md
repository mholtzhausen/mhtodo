**mhtodo** is a personal todo manager: one Go binary with a scriptable CLI for agents and a Wails GUI + system tray for humans. This blog covers release notes and how to work with agents (especially Claude) against the live board.

Browse posts below, or read the Markdown sources in [`docs/_posts`](https://github.com/mholtzhausen/mhtodo/tree/main/docs/_posts) on GitHub. The full changelog stays in [`CHANGELOG.md`](https://github.com/mholtzhausen/mhtodo/blob/main/CHANGELOG.md).
