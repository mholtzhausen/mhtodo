# 05 — Detail pin and list columns

## Pin

- `localStorage['mhtodo.detailPinned']`
- Unpinned: fixed overlay drawer (current)
- Pinned: flex shell, main shrinks, in-flow 420px pane; collapse when no selection

## List columns

Drop ID. Status column: pill + progress bar below. Title takes remaining width.
Updated: elapsed top; absolute below (time-only if today, else date+time).
